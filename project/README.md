# Pi Ensemble development tracker

## Goal and strategy

Deliver a functioning, local-first durable multi-agent runtime with persistent directly addressable agents and attachable clients. Research the substrate and real workflow, implement the smallest recovery-tested slice, then expand under explicit review and operator control.

Current phase: requirements, work-setup evidence, upstream analysis, and design. No functioning runtime exists yet.
