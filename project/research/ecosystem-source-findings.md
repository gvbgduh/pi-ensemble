## Cross-source takeaways

1. **Retained child ≠ persistent logical agent.** The latest subagents package solves useful bounded continuation: locate a finished child, validate that its transcript/context is resumable, then ask it to continue under its original contract. Ensemble's desired continuously addressable logical agent still needs an application registry, stable address/incarnation rules, independent steering, ownership/epochs and context replacement. Receipt/run ID is a continuation reference, not the product identity.
2. **A receipt hierarchy is useful, but layers must be named.** A message receiver receipt, a Durable input submission receipt, a child terminal result, and an external-action reconciliation receipt are different facts. Do not collapse “delivered” into “accepted,” “understood,” “completed,” or “effect happened.”
3. **Use a single replay owner.** Cloudflare's SDK and examples let Durable own transcript/input/task replay while host owns wake, transport, policy and UI. Avoid a second transcript replay engine; make Ensemble's host logic explicit above Durable.
4. **Local attach is privileged execution.** Pocket demonstrates mature UI-level roles and also accurately notes their limit: a steering client may cause execution with the host's filesystem/provider privileges. Enforce host-side capabilities, scope, least privilege, and clear threat boundaries; browser visibility is not a sandbox.
5. **Treat source caveats as product inputs.** Broker-local mailboxes disappear at broker restart; cancellation after injection cannot revoke work; remote demo code needs auth/rate-limits; a host restart/lost workspace may invalidate child resume. These are useful test scenarios, not details to hide in a prompt.
6. **No behavior below is independently reproduced.** Source tests are evidence of intended assertions and implementation structure only. The APIs and results are not verified by execution in this task.
