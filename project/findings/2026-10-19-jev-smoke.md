# Jev authentication and codemode smoke test

Date: 2026-10-19. Status: **reproduced successful direct TypeSafe calls**, not general decision-quality validation.

## Method and observations

Pi 1.3.0 codemode and standalone tool search are callable. Tool search returned no separate classifier tool; this is expected because native classifiers use `models`, not a deferred MCP tool. `models.getAvailableOfType("classifier", "typesafe")` listed `jev-latest` without inspecting credentials. Three sequential `models.classify` calls used public synthetic acceptance evidence and the same neutral `acceptance-evidence-v1` choice rubric. Caller baselines were stored separately and not sent to Jev.

| Case | Observations | Result | Confidence | Input/output tokens | Duration |
| --- | --- | --- | --- | --- | --- |
| complete | Required positive and negative tests passed | supported | 0.97 | 428 / 46 | 291 ms |
| incomplete | Required negative test explicitly failed | contradicted | 1 | 428 / 49 | 195 ms |
| unknown | No test results available | insufficient | 1 | 420 / 49 | 201 ms |

All three returned `stopReason: stop`. Total reported usage: **1,276 input / 144 output tokens**. At the operator-reported rate of $0.042/M input and $0 output, estimated cost is **$0.000053592**. Native cost fields were zero; that is not billing proof. Returned model identity is the moving alias `jev-latest`, with no immutable revision reported. Detailed public synthetic requests, baseline, probabilities, usage and returned timestamps are in [the structured record](2026-10-19-jev-smoke.json).

## Interpretation and limits

Authentication and the native codemode call path work. Three trivial labeled cases do not validate neutrality, calibration, production triage quality, authorization, or runtime recovery. No controlled paraphrase/order/polarity tests, unavailable-service injection, Durable adapter, or reusable instrumentation was run. No secrets or private workplace data were read or sent. Retain failure visibility and explicit unknown costs/revisions in subsequent implementation.
